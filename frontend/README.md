# CloudSentry dashboard

React + TypeScript + Vite UI for the local API. The UI sends local filesystem paths to the API process, so use only with a trusted local API. This is an early development interface, not for public deployment.

    npm install
    npm run dev

API should be running at http://127.0.0.1:8000. CORS is restricted to localhost/127.0.0.1 port 5173.
